# Íconos del stack

Las insignias combinan texto con pictogramas. Las siluetas de marcas proceden de Simple Icons 14.0.0 (CC0 1.0). Los símbolos de API HTTP y análisis estadístico son dibujos propios. Las marcas identifican el software usado y pertenecen a sus titulares.
